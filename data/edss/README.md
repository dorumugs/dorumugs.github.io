# EDSS 교육데이터 — 중학교 졸업생 진로 현황

> **2026-07 갱신.** 학교별 진학률은 **학교알리미 웹 공시에서 받아 쓰고 있다**
> (`scripts/schoolinfo_api.py`). 이 EDSS 파일은 더 이상 화면에 쓰이지 않고,
> 시·도 단위 장기 추이(2009~2025, `progression.json`)의 원본으로만 남는다.
> 아래 "공개 경로 어디에도 없다" 는 옛 결론은 **틀렸다** — 뒤집힌 경위는 이 문서
> 끝의 「학교알리미 경로를 찾은 경위」 참고.

## 파일

`중학교_졸업생진로현황_2009-2025.csv.gz`

- 출처: 에듀데이터서비스(EDSS, `edss.moe.go.kr`) 신청·다운로드 자료
  원본 파일명 `0317. 졸업생진로현황_중(09-25).csv`
- 원본 인코딩 cp949 → **UTF-8 로 정규화**해 저장 (cp949 는 도구마다 깨진다)
- 57,929행 / 2009~2025 공시년도 / 44개 컬럼
- 2025년 서울·경기만 **1,147개교**

## 지금 쓰는 곳

`scripts/build_progression.py` → `assets/realestate/progression.json`
(시·도 단위 진학률 추이, 2011~2025).

학교를 특정할 수 없어도 시·도 합계는 낼 수 있다. **학교알리미는 최근 3년치만
공시**하므로 15년 추이는 이 파일로만 만들 수 있다 — 두 자료는 대체 관계가 아니라
역할이 다르다.

## 쓸 수 있는 컬럼

특목고·자사고 진학자 = 아래 셋의 합 (남 + 여):

```
특수과학고진학남/여학생수      과학고
특수외국어고진학남/여학생수    외고·국제고
자율사립고진학남/여학생수      자사고
```

분모: `졸업생진로_중_남자졸업생수` + `졸업생진로_중_여자졸업생수`

그 외: 일반고 / 특성화고 / 특수예술고 / 특수직업고 / 자율공립고 / 종합고 /
전문계열 / 일반계열 / 취업 / 미진학(무직·미상) — 전부 남녀 분리.

## 학교를 특정할 수 없다 (이 파일의 한계)

**이 파일에는 학교명도 주소도 없다.** 식별자가 `개방ID`(10자리 숫자,
예 `5271502077`) 하나뿐이고, 우리 위치 데이터(`data/schools.csv.gz`)의
`school_id` 는 `B000008085` 형식이라 **교집합이 0** 이다.

시도한 연결 방법과 결과:

- 학교알리미 OpenAPI 응답 15종의 **모든 필드**를 개방ID 값과 대조 → 일치 없음
- `SHL_IDF_CD` → UUID 형식이라 무관
- 졸업생 남/여 수를 지문으로 `apiType=51` 의 `MAN_SUM`/`WOMAN_SUM` 과 매칭
  → 그 값은 재학생 수라 24교 중 1교만 우연히 일치
- `졸업생진로_중_최종학년남/여학생수` 로 매칭 → **이 컬럼은 전 행이 0** 이라 불가
- (2026-07 추가) NEIS 표준학교코드 1,085개와 대조 → 교집합 0.
  개방ID 앞 2자리 분포가 서울·경기 모두 `10~99` 에 균일해 지역 정보조차 없다 —
  익명화용 난수로 보는 게 맞다
- (2026-07 추가) 최근 3년 남/여 졸업생 수를 지문으로 쓰면 1,147곳 중
  **1,132곳(98.7%)이 유일**하다. 이름 붙은 졸업생 수 시계열만 있으면 식별되지만,
  학교알리미 `apiType=51` 의 졸업생 수는 EDSS 어느 연도에도 없어(개원중 94/239,
  압구정중 91/67 미발견) 서로 다른 모집단을 센다

결론: **개방ID ↔ 학교명 매핑은 EDSS 공개 목록에 없다.** 개방데이터 목록
(`edmgr.kr` 학교정보공시 탭 81건 · 교육통계 탭 105건)을 전수 확인했는데 전부
시도교육청·학교급 단위 집계이고 `개방ID` 도 `학교명` 도 컬럼에 없다. 학교 단위
행이 있는 신청 자료는 익명화되어 나오므로, 매핑을 받는 건 정책상 어려울 수 있다.

## 학교알리미 경로를 찾은 경위 (2026-07)

「졸업생의 진로 현황」은 **중·고·특·각 대상 연 1회(11월) 공시 항목**이고,
학교알리미 **학교별 공시 화면**에서 학교명과 함께 조회된다:

```
GET https://www.schoolinfo.go.kr/ei/pp/Pneipp_b06_s0p.do
    ?GS_HANGMOK_CD=06&SHL_IDF_CD=<학교 UUID>&JG_YEAR=2025 ...
```

- 응답은 **cp949** 다. UTF-8 로 읽으면 표가 통째로 깨져 "데이터 없음" 으로 오인한다
- 학교 목록은 `pneiss_a03_s0_school_json.do` (`HG_JONGRYU_GB=03` 이 중학교)
- 자세한 파라미터와 파싱은 `scripts/schoolinfo_api.py`

옛 결론이 틀렸던 이유는 확인한 경로가 달랐기 때문이다. **OpenAPI 에 없다는 것은
지금도 맞다**(파라미터를 모두 채워 `apiType` 0~139 를 다시 전수 호출해도 진학
유형별 항목은 없다). 「항목별 공시정보」(지역 일괄 조회)에도 2023~2026 전 연도·전
분류에 이 항목이 없다. 있는 곳은 **학교별 공시 화면 하나뿐**이라, 학교 하나에
요청 하나씩 보내는 수집이 된다(서울·경기 1,436곳 × 3년).
