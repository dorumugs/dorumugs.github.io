## Summary

"Copilot 으로 뭐 할 수 있어요?" 라는 질문에 한마디로 답하기가 의외로 어려워요. **Copilot 이라는 이름이 가리키는 제품이 한 개가 아니거든요.** Word 안에서 초안을 써주는 것도 Copilot, Edge 에서 웹을 요약해주는 것도 Copilot, VS Code 에서 코드를 짜주는 것도 Copilot 입니다. 같은 브랜드인데 들어가는 자리와 할 수 있는 일이 전부 달라요.

이 글에서는 마이크로소프트가 **Copilot** 이라는 이름으로 묶어둔 네 갈래 — 오피스 업무용, 일반 소비자용, 개발자용, 그리고 직접 만드는 쪽 — 를 한 장의 지도처럼 정리합니다. 제품마다 "구체적으로 뭘 시킬 수 있는지" 를 표와 예시 프롬프트로 보여줄게요.

> 💡 **이 글에서 다루는 것**
> - **Copilot 이라는 이름이 가리키는 4개 제품** 의 지도
> - **Microsoft 365 Copilot** — Word·Excel·PowerPoint·Outlook·Teams 업무 자동화
> - **소비자용 Microsoft Copilot** — 채팅·웹 검색·이미지 생성·Vision·Windows/Edge 통합
> - **GitHub Copilot** — 코드 자동완성·Chat·코딩 에이전트·PR 리뷰
> - **Copilot Studio / Security Copilot** — 직접 만드는 커스텀 에이전트, 보안 운영
> - 상황별 "그래서 뭘 켜야 하나" 선택 가이드

> ⚠️ 기능과 제품 구성은 마이크로소프트가 자주 개편해요. 이 글은 2026년 상반기 기준이고, 같은 기능이라도 요금제(개인용 / 직장·학교용)에 따라 보이는 메뉴가 다를 수 있어요.

## 1. 먼저 지도부터 — Copilot 은 한 제품이 아니에요

가장 헷갈리는 지점부터 풀고 갈게요. 마이크로소프트의 Copilot 은 크게 **네 갈래**로 나뉩니다. 어디에 들어가 있고, 누가 쓰고, 무엇을 시킬 수 있는지가 다 달라요.

| 제품 | 들어가는 자리 | 주로 하는 일 | 비용 감각 |
|---|---|---|---|
| **Microsoft 365 Copilot** | Word · Excel · PowerPoint · Outlook · Teams 안 | 내 문서·메일·일정 기반 업무 자동화 | 유료(직장·학교 구독에 좌석 추가) |
| **소비자용 Microsoft Copilot** | copilot.microsoft.com · Windows · Edge · 모바일 앱 | 일반 채팅·웹 검색·이미지 생성·요약 | 무료 + Copilot Pro(유료) |
| **GitHub Copilot** | VS Code · Visual Studio · JetBrains · github.com | 코드 작성·설명·리뷰·에이전트 | 무료 티어 + 유료 플랜 |
| **Copilot Studio** | 웹 제작 도구(Power Platform) | 내가 직접 만드는 커스텀 Copilot/에이전트 | 유료(메시지 단위 과금) |

여기에 더해 보안팀 전용인 **Security Copilot** 같은 특화 제품도 있어요. 핵심만 잡으면 이래요.

> 💡 **한 줄 구분법**
> - 내 **회사 문서·메일** 을 다루면 → Microsoft 365 Copilot
> - 그냥 **물어보고 검색·이미지** 면 → 소비자용 Copilot
> - **코드** 면 → GitHub Copilot
> - 우리 팀만의 **챗봇/에이전트를 만들고** 싶으면 → Copilot Studio

아래부터는 갈래별로 "실제로 뭘 시킬 수 있는지" 를 하나씩 풀어볼게요.

## 2. Microsoft 365 Copilot — 오피스 업무를 시키는 쪽

직장인이 "Copilot" 하면 가장 먼저 떠올리는 게 이거예요. Word·Excel·PowerPoint·Outlook·Teams **안에** 들어가서, 내 문서·메일·일정·채팅을 근거로 일을 대신 해줍니다. 일반 챗봇과 결정적으로 다른 점은 **내 조직의 데이터(Microsoft Graph)** 에 접근한다는 거예요. "지난주 김부장 메일에서 합의된 일정" 같은 걸 알고 답합니다.

### 앱별로 할 수 있는 일

| 앱 | 시킬 수 있는 작업 | 예시로 던지는 말 |
|---|---|---|
| **Word** | 초안 작성, 문서 요약, 톤 바꾸기, 표로 정리 | "이 회의록을 3문단 보고서 초안으로 바꿔줘" |
| **Excel** | 수식 제안, 데이터 분석, 추세·이상치 찾기, 표 정리 | "이 매출 표에서 분기별 성장률 열을 추가하고 이상치를 표시해줘" |
| **PowerPoint** | Word 문서를 슬라이드로, 디자인 제안, 발표자 노트 | "이 기획서를 10장짜리 발표 자료로 만들어줘" |
| **Outlook** | 긴 메일 스레드 요약, 답장 초안, 받은 편지함 정리 | "이 스레드 핵심만 요약하고 정중한 답장 초안 써줘" |
| **Teams** | 회의 실시간/사후 요약, 안건·결정사항·액션아이템 추출 | "내가 늦게 들어왔는데 지금까지 회의 내용 정리해줘" |
| **OneNote / Loop** | 노트 요약, 계획 정리, 브레인스토밍 | "이 노트들을 다음 주 실행 계획으로 묶어줘" |

### Copilot Chat 과 Pages — 앱 밖에서 조직 데이터를 묻기

특정 앱이 아니라 **Copilot Chat**(예전 Business Chat)에서 조직 전체 데이터를 가로질러 물어볼 수도 있어요. 메일·파일·회의·채팅을 한꺼번에 근거로 삼습니다.

- "지난 분기 마케팅 프로젝트 관련 문서랑 메일을 모아서 현재 상태 요약해줘"
- "다음 주 출장 준비물 체크리스트를 관련 메일 기반으로 만들어줘"

결과를 **Pages** 라는 협업 캔버스에 붙여서 동료와 같이 다듬는 흐름도 있어요. 채팅으로 뽑은 초안을 바로 팀 문서로 끌어올리는 식이에요.

> ✅ 핵심은 "**내 데이터에 근거한다**" 예요. 그래서 회사 보안·권한 설정에 따라 접근 가능한 범위가 정해지고, 내가 못 보는 파일은 Copilot 도 못 봅니다.

## 3. 소비자용 Microsoft Copilot — 그냥 물어보고 시키는 쪽

로그인 없이도, 혹은 개인 Microsoft 계정으로 쓰는 일반용 Copilot 이에요. `copilot.microsoft.com`, Windows 작업표시줄, Edge 사이드바, 모바일 앱에 들어가 있어요. 회사 문서 연동은 없지만 **웹·일상 작업** 에 강합니다.

### 할 수 있는 일

| 분류 | 시킬 수 있는 작업 | 예시 |
|---|---|---|
| **질문·글쓰기** | 설명·요약·번역·초안·아이디어 | "이 개념을 중학생도 알게 설명해줘" |
| **웹 검색 결합** | 최신 정보 검색 후 출처와 함께 답변 | "이번 주 환율 동향 출처 링크까지 정리해줘" |
| **이미지 생성** | 텍스트로 그림 만들기(Designer 기반) | "수채화 느낌의 가을 산책로 그려줘" |
| **문서·이미지 업로드** | 파일/사진 올려서 요약·분석·질문 | (PDF 올리고) "이 계약서 핵심 조항만 뽑아줘" |
| **Copilot Vision** | 화면·카메라에 보이는 걸 같이 보며 안내 | "지금 보는 이 화면에서 뭘 눌러야 해?" |
| **음성 대화** | 말로 묻고 말로 답받기 | 운전 중 핸즈프리 질의응답 |

### Windows / Edge 안에서의 통합

- **Windows** — 작업표시줄이나 단축키로 불러서 설정 바꾸기, 화면 내용 질문, 앱 안내.
- **Edge** — 지금 보는 웹페이지나 PDF 를 사이드바에서 바로 요약·번역·질문.
- **Copilot Pro**(유료) — 더 빠른 응답, 사용량 우선권, Word/Excel 같은 개인용 오피스 앱 안의 Copilot 기능 등이 붙어요.

> 💡 회사 계정으로 로그인하면 같은 화면이 **업무용 Copilot Chat** 으로 바뀌어서 조직 데이터 보호 범위 안에서 작동해요. "어, 회사에서 쓰는 Copilot 이랑 집에서 쓰는 게 왜 달라?" 의 정체가 이거예요.

## 4. GitHub Copilot — 코드를 시키는 쪽

개발자용 Copilot 이에요. VS Code·Visual Studio·JetBrains·Neovim 같은 에디터와 `github.com` 안에서 작동합니다. 단순 자동완성에서 시작해 지금은 **에이전트** 수준까지 넓어졌어요.

### 할 수 있는 일

| 기능 | 하는 일 | 어디서 |
|---|---|---|
| **코드 자동완성** | 타이핑 중 다음 줄·블록 제안 | 에디터 인라인 |
| **Copilot Chat** | 코드 설명·리팩터링·버그 원인·테스트 작성 질문 | 에디터 사이드 패널 |
| **인라인 편집** | 선택한 코드를 자연어 지시로 수정 | 에디터 |
| **코딩 에이전트** | 이슈를 받아 여러 파일을 고치고 PR 까지 생성 | github.com / 에디터 |
| **PR 리뷰** | 풀 리퀘스트에 자동으로 리뷰 코멘트 | github.com |
| **CLI 지원** | 셸에서 명령어 추천·설명 | 터미널 |

### 예시로 시키는 말

```text
- "이 함수가 뭘 하는지 설명하고, 엣지 케이스 테스트를 추가해줘"
- "이 반복문을 더 읽기 좋게 리팩터링해줘"
- "#142 이슈를 해결하는 PR 을 만들어줘"   ← 에이전트
- "이 에러 스택트레이스 원인이 뭐야?"
```

특히 **코딩 에이전트** 는 "이슈 → 코드 수정 → PR" 까지를 사람 개입 없이 한 바퀴 돌리는 게 가능해진 부분이에요. 자동완성만 쓰던 시절과 체감이 꽤 달라요. AI 코딩 도구를 여러 개 비교한 글이 따로 있으니 흐름이 궁금하면 [AI 코딩 CLI 3종 비교 글](/coding/AI_코딩_CLI_3종_비교/)도 같이 보세요.

> ⚠️ 에이전트가 만든 PR 이라도 머지 전 리뷰는 사람 몫이에요. 그럴듯해 보여도 의도와 다르게 고쳐놓는 경우가 있어서, 자동완성이든 에이전트든 **결과를 읽고 넘기는 습관**은 그대로 가져가야 해요.

## 5. 직접 만드는 쪽 — Copilot Studio 와 Security Copilot

여기서부터는 "쓰는" 게 아니라 "만드는" 영역이에요.

### Copilot Studio — 우리 팀만의 Copilot 만들기

코드 없이(로우코드) **커스텀 Copilot/에이전트** 를 만드는 도구예요. 사내 위키·매뉴얼·DB 를 지식으로 연결해서, 직원이나 고객 질문에 답하는 챗봇을 만들 수 있어요.

| 만들 수 있는 것 | 예시 |
|---|---|
| **지식 기반 Q&A 봇** | 사내 규정·매뉴얼을 학습한 HR 헬프데스크 |
| **업무 자동화 에이전트** | "휴가 신청 들어오면 승인 라우팅" 같은 흐름 |
| **외부 시스템 연동** | 커넥터로 사내 시스템·API 호출 |
| **Teams·웹사이트 배포** | 만든 봇을 채널에 붙이기 |

Microsoft 365 Copilot 안에 **에이전트** 로 꽂아서, 평소 쓰던 Copilot Chat 에서 우리 팀 전용 기능을 부르게 만들 수도 있어요.

### Security Copilot — 보안 운영 전용

SOC(보안관제) 팀을 위한 특화 Copilot 이에요. 보안 사고를 조사하고, 위협 인텔리전스를 요약하고, 인시던트 대응을 돕습니다. 자연어로 "이 알림이 진짜 위협인지 분석해줘" 같은 걸 시킬 수 있어요. 일반 사용자용은 아니고 보안 담당자용입니다.

> 💡 AI 를 보안 공격/방어에 쓰는 더 넓은 이야기는 [AI 보안 시리즈](/coding/AI_보안_2_방어_탐지_대응/)에서 따로 다뤘어요.

## 6. 그래서 뭘 켜야 하나 — 상황별 선택

이름이 다 같으니, 결국 "지금 내 상황에 어느 Copilot 이 맞나" 만 잡으면 돼요.

| 하고 싶은 일 | 켜야 할 Copilot |
|---|---|
| 회사 메일·문서·회의 정리 | **Microsoft 365 Copilot** |
| 그냥 검색하고 물어보고 이미지 만들기 | **소비자용 Copilot**(무료/Pro) |
| 개인 Word·Excel 안에서 글쓰기 보조 | **Copilot Pro**(개인용) |
| 코드 작성·리뷰·버그 추적 | **GitHub Copilot** |
| 사내 데이터 기반 챗봇/에이전트 제작 | **Copilot Studio** |
| 보안 사고 조사·대응 | **Security Copilot** |

정리하면, **"내 회사 데이터를 다루느냐 / 코드냐 / 만드는 거냐"** 세 갈래만 머리에 넣어두면 어떤 Copilot 을 말하는 건지 헷갈릴 일이 줄어요. 같은 브랜드라 메뉴가 비슷해 보여도, 접근하는 데이터와 작동 자리가 다르다는 게 전부거든요.
