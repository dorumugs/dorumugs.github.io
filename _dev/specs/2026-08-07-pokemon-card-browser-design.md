# 포켓몬 카드 현재가 브라우저 설계

작성 2026-08-07 · 이전 설계 `2026-08-07-pokemon-dashboard-design.md` 를 **대체**한다

## 왜 다시 만드는가

앞선 설계는 "정직한 시장지수"를 만들었다. 5부작 글의 문제제기를 잇는다는
점에서는 맞았지만, **사용자가 원한 물건이 아니었다.**

원하는 것은 이렇다.

- 앞으로의 값(추이·지수)이 아니라 **지금 이 카드가 얼마인가**
- **영어 이름과 한글 이름을 같이**
- **카드 사진**
- **가장 높게 팔렸던 금액**

지수는 "시장 전체가 어디로 가나"에 답하는 도구다. 사용자가 묻는 건
"이 카드 얼마냐"다. 다른 질문이므로 다른 화면이 필요하다.

지수 대시보드는 **없앤다.** 화면·집계·지수 계산 코드를 지우고 수집기만 살려
카드 브라우저로 돌린다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 기존 지수 | 없애고 카드 브라우저로 교체 |
| 범위 | 가격이 잡히는 카드 **전부** (약 17,700장) |
| 최고가 | **현재 최고 호가 + 관측 최고가 둘 다**, 구분해 표시 |
| 통화 | USD(TCGplayer) 기준, EUR(Cardmarket) 병기 |

## 1. 요구사항별 실현 가능성

조사해서 확인한 사실이다. 못 하는 것을 할 수 있는 척하지 않는다.

| 요청 | 가능 | 근거 |
|---|---|---|
| 현재가 | ○ | TCGplayer `marketPrice`, Cardmarket `avg` |
| 카드 사진 | ○ | TCGdex 이미지 CDN. 썸네일 `low.webp` 20KB, 원본 `high.webp` 78KB |
| 영어 이름 | ○ | 카드 응답 `name` |
| 한글 이름 | △ | 아래 |
| 역대 최고 낙찰가 | **×** | 아래 |

### 한글 이름 — 포켓몬만 된다

TCGdex 는 한국어 엔드포인트(`/v2/ko/`)를 제공하지만 **데이터가 사실상 비어
있다.** 95개 세트 중 카드가 채워진 세트는 3개, 7,646장 중 235장뿐이다
(2026-08-07 실측). 쓸 수 없다.

대신 카드마다 `dexId`(전국도감 번호, 배열)가 있다. **PokéAPI** 의
`pokemon-species/{id}` 가 종 이름을 한국어로 준다. 이걸 조인한다.

| 카드 | 영문 | 한글 |
|---|---|---|
| base1-4 | Charizard | 리자몽 |
| xy2-11 | Charizard EX | 리자몽 EX |
| base1-102 | Water Energy | (없음) |

**한계를 화면에 명시한다.** 이건 *포켓몬 종 이름*이지 카드 정식 한글명이
아니다. 트레이너·에너지 카드는 도감번호가 없어 한글명이 없다. 접미사(EX·GX·V)
는 영문 그대로 둔다.

### 역대 최고 낙찰가 — 없다

무료로 열린 어떤 API 도 "역대 최고 낙찰가"를 주지 않는다. 줄 수 있는 건 둘뿐이다.

| 이름 | 정체 | 주의 |
|---|---|---|
| 현재 최고 호가 | TCGplayer `highPrice` — 지금 시장에 올라온 가장 비싼 **매물** | 팔린 값이 아니다. 터무니없는 호가가 섞인다 |
| 관측 최고가 | 우리가 매일 재면서 본 `marketPrice` 의 최댓값 | 수집 시작(2026-08-07) 이후만. 오늘은 현재가와 같다 |

둘을 **다른 이름으로 나란히** 보여주고, 각각이 무엇인지 화면에 적는다.
"최고가"라고 뭉뚱그리면 역대 낙찰가로 오해된다.

## 2. 데이터

### 소스

| 소스 | 쓰는 것 | 키 |
|---|---|---|
| TCGdex `/v2/en` | 카드 메타·이미지·가격 | 불필요 |
| PokéAPI `pokemon-species` | 도감번호 → 한글 종 이름 | 불필요 |

PokéAPI 는 User-Agent 가 없으면 403 이다. 반드시 붙인다.

### 카드 저장

`data/pokemon/cards.csv.gz` **한 파일**에 메타와 가격을 같이 둔다. 시계열을
쌓지 않으므로(현재가만 본다) 파일이 하나면 충분하다.

| 컬럼 | |
|---|---|
| `card_id` `set_id` `local_id` | 키 |
| `name_en` `dex_id` `rarity` `category` `image` | 메타. `image` 는 `base/base1/4` 같은 짧은 경로 |
| `tp_market` `tp_low` `tp_mid` `tp_high` | TCGplayer USD |
| `cm_avg` `cm_low` `cm_trend` | Cardmarket EUR |
| `obs_max` `obs_max_date` | 관측 최고가와 그날 |
| `updated` | 마지막 수집일 |

**일별 이력을 쌓지 않는다.** 17,700장 × 365일이면 연 646만 행이다. 현재가만
보는 화면에 그걸 들고 있을 이유가 없다. 대신 `obs_max` 를 갱신하며 이어간다.

앞 설계의 `prices.csv.gz`(300장 시계열)·`universe.json`·`scan.csv.gz` 는 지운다.

`data/pokemon/species_ko.json` — 도감번호 → 한글 이름. 1,025종, 1회 수집.

### 갱신 비용

카드 1장당 1요청, 동시 4로 약 4.4 req/s (실측). 17,700장이면 **약 70분**.
크론은 밤에 도니 문제없다. `flock -w 7200` 안에 들어간다.

## 3. 화면

`/dashboard/pokemon/` 을 카드 브라우저로 바꾼다.

### 첫 화면

검색이 먼저다. "이 카드 얼마냐"가 질문이므로 찾는 것부터 되어야 한다.

- 검색창 — **영문·한글 둘 다** 매칭 (`리자몽`, `charizard` 모두)
- 필터 — 세트 · 시대 · 등급
- 정렬 — 현재가 높은/낮은 순, 이름순
- 결과 — **이미지 카드 그리드**

### 카드 하나에 보이는 것

| 항목 | 표시 |
|---|---|
| 사진 | `low.webp` 썸네일, 누르면 원본 |
| 이름 | 영문 (크게) + 한글 (작게, 있을 때만) |
| 세트·번호·등급 | 한 줄 |
| **현재가** | TCGplayer market USD — 가장 크게 |
| 현재 최고 호가 | `highPrice` |
| 관측 최고가 | `obs_max` + 날짜 |
| Cardmarket | EUR 평균 |

### 용량

17,700장을 한 번에 내려받아야 검색이 즉시 된다. **객체 대신 배열**로 저장해
키 반복을 없앤다.

```
["base1-4", "base1", "4", "Charizard", "리자몽", "Rare", 818.65, ...]
```

목표는 gzip 후 **400KB 이하**. 넘으면 검색 인덱스와 상세를 분리한다.
빌드 때 실제 크기를 재서 기록한다.

이미지는 **지연 로딩**(`loading="lazy"`)한다. 한 화면에 수십 장이 뜨는데 미리
받으면 안 된다.

## 4. 파이프라인

| 파일 | 역할 | 변경 |
|---|---|---|
| `scripts/tcgdex_api.py` | 파싱 순수 함수 | 지수 계산 제거, `parse_card_full` 추가 |
| `scripts/pokeapi.py` | 도감번호→한글명 파싱 | **신규** |
| `scripts/collect_pokemon.py` | 전 카드 스윕·예산·재개 | 재작성 |
| `scripts/build_pokemon.py` | 컴팩트 JSON 생성 | 재작성 |
| `scripts/pokemon_daily.sh` | 크론 진입점 | 모드 정리 |

지수 전용 함수(`stratify` `tercile_bounds` `band_of` `fill_forward`
`index_point`)와 그 테스트는 **지운다.** 안 쓰는 코드를 남기면 다음 사람이
이게 살아 있는 줄 안다.

`era_of` 와 `ERAS` 는 남긴다 — 시대 필터로 계속 쓴다.

## 5. 크론

시각·flock 은 그대로. 스크립트가 하는 일만 바뀐다.

```
30 7 * * * flock -w 7200 ~/.cache/realestate.lock ... pokemon_daily.sh
```

전 카드 스윕이 70분이므로 `--max-calls` 로 끊지 않고 한 번에 돈다. 중간에
죽어도 세트마다 저장하므로 다음 실행이 이어받는다.

## 6. 검증

- 표준 `unittest`. 파싱·조인·최고가 갱신 로직에 테스트를 붙인다.
- 390px 오버플로 없음. 그리드는 좁은 화면에서 2열로 접힌다.
- 이미지 404 가 나도 화면이 깨지지 않는다 (`onerror` 처리).
- 링크 e2e.

## 범위 밖

- 지수·시계열 (이번에 걷어낸다)
- 국내 원화 시세 (공개 API 없음)
- PSA 등급별 가격
- 카드 정식 한글명 (공개된 데이터가 없다. 종 이름으로 대신한다)
