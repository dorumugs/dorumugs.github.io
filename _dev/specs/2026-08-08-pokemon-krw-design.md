# 포켓몬 카드 국내(원화) 시세 설계

작성 2026-08-08 · `2026-08-07-pokemon-card-browser-design.md` 를 **보완**한다
(대체하지 않는다 — 글로벌 카드 브라우저는 그대로 두고 탭 하나를 옆에 붙인다)

## 왜 다시 여는가

앞선 설계는 국내 원화 시세를 **범위 밖**으로 적어 두었다. 근거는 두 가지였다.

| 당시 판단 | 지금 확인된 사실 |
|---|---|
| 공개 API 가 없다 | 있다. `api.kream.co.kr/api/data_mart/serving/trading_pokemon_card` |
| 서명 헤더 우회 + 계정 세션 쿠키가 필요하다 | **둘 다 필요 없었다.** 아래 참조 |

시세표 페이지(`content.kream.co.kr/pokemon-tcg-chart`)는 **로그인 없이 열린다.**
페이지를 그대로 열면 그 페이지가 스스로 서명을 만들어 요청하므로, 우리가
서명을 흉내 낼 이유도 남의 세션 쿠키를 빌릴 이유도 없다.

## 1. 수집 — 관문은 User-Agent 하나였다

실측 기록이다. 다음 사람이 같은 벽에 부딪히지 않도록 남긴다.

| 시도 | 결과 | 해석 |
|---|---|---|
| `curl` (헤더 없음 / 브라우저 헤더 / `x-kream-*` 4종) | 모두 **500**, 본문 0바이트 | Chrome 이 아닌 TLS 지문을 엣지에서 걷어낸다 |
| `api.kream.co.kr/api/health` | 500 | 경로와 무관하다 |
| Nuxt 프리렌더 `_payload.json` | 69바이트, 데이터 없음 | HTML 만 받아서는 못 얻는다 |
| 헤드리스 Chrome, 기본 UA | 프리플라이트 **500** → `net::ERR_FAILED` | UA 에 `HeadlessChrome` 이 박혀 있다 |
| 헤드리스 Chrome, **평범한 Chrome UA** | **200**, 시세 렌더됨 | 관문은 이것 하나였다 |

즉 **봇 차단이 아니라 UA 문자열 필터**다. 서명도, 쿠키도, 세션도 필요 없다.

### 응답을 어떻게 손에 넣는가

세 가지를 시도했고 앞의 둘은 실패했다.

| 방법 | 결과 |
|---|---|
| `Network.getResponseBody` | `No resource with given identifier found`. 5.5MB XHR 은 캐시에서 밀린다 |
| `Fetch.requestPaused` 로 응답 단계에서 가로채기 | **GET 이 500 이 된다.** 붙잡는 동안 `x-kream-client-datetime` 과 짝인 서명이 만료된다 |
| **`fetch` 를 감싸 페이지 안에 쟁여 두기** | 된다. 요청을 늦추지 않으므로 서명이 살아 있다 |

세 번째를 쓴다. `Page.addScriptToEvaluateOnNewDocument` 로 페이지 JS 보다 먼저
`fetch`·`XMLHttpRequest` 를 감싸 본문만 `window.__kream` 에 넣어 두고, 다 받은
뒤에 조각내어 꺼내온다.

**감쌀 때 `origFetch.apply(window, args)` 로 부를 것.** `apply(this, …)` 로 두면
페이지가 `fetch(...)` 를 그냥 부를 때 strict mode 에서 `this` 가 `undefined` 가
되어 *Illegal invocation* 으로 요청이 통째로 죽는다. 이 한 줄 때문에 여섯 번을
연달아 실패했다.

### 서버가 자주 죽는다

KREAM 이 간헐적으로 500 을 낸다. 그때는 KREAM 자기 화면도
"일시적인 오류가 발생했습니다" 를 띄운다. 우리 잘못이 아니다.

그래서 **실패하면 기존 파일을 건드리지 않고 물러난다.** 마지막 정상 스냅샷이
남는 편이 빈 화면보다 낫다. 크론은 이 실패를 전체 실패로 치지 않는다 — 단,
한 번도 받은 적이 없으면 실패다.

수동 경로도 남긴다. `--from-file` 로 브라우저에서 받아둔 응답을 그대로 넣을 수
있다. 수집기가 막히더라도 파이프라인이 굴러간다.

**2026-08-08 08:51 크론에서 라이브 캡처가 성공했다** (899종·31일). 개발 중
1시간 40분 동안 연달아 실패한 건 우리 코드가 아니라 KREAM 쪽 상태였다.
헤드리스 캡처 자체는 정상 동작한다.

### 실행 중인 셸 스크립트를 고치지 말 것

크론이 `pokemon_daily.sh` 를 돌고 있는 중에 그 파일에 줄을 끼워 넣었더니,
**그날 등급 시세 단계가 통째로 건너뛰어졌다.** bash 는 스크립트를 한 번에
읽지 않고 바이트 오프셋으로 이어 읽기 때문에, 앞쪽에 줄이 늘면 다음 읽기가
엉뚱한 지점에서 시작한다. 문법 오류로 죽지도 않아서 조용히 한 단계가 사라진다.

고치기 전에 `pgrep -af pokemon_daily` 로 확인할 것. 돌고 있으면 끝난 뒤에
고친다.

## 2. 데이터

응답은 두 덩어리다.

| 덩어리 | 내용 |
|---|---|
| `market.rows` | 하루 한 줄, 31일. 그날 거래 전체의 중앙값·건수·저가·고가·평균·거래대금 |
| `product.rows` | 상품 899종. 한/영 이름, 이미지, 품번, 최근 중앙값, 1·7·30일 변동률, 30일 고저, 31일 가격 이력 |

### 파싱에서 조심할 것

| 함정 | 처리 |
|---|---|
| 변동률이 `'-1.72E1'` 같은 **지수표기 문자열** | `parse_pct` 가 −17.2 로 바꾼다 |
| 값이 없으면 `'-'` | **`None` 으로 둔다. 0% 로 바꾸지 않는다.** "안 움직였다" 가 아니라 "거래가 없어 모른다" 는 뜻이라, 0 으로 적으면 없는 사실을 지어내는 게 된다 |
| 이름이 전부 `포켓몬 TCG ` / `Pokemon TCG ` 로 시작 | 떼어낸다 (899/899 해당) |
| 이름 끝 `(Japanese Ver.)` | 언어 필드로 뽑는다 |
| 중앙값이 `154812.5` 처럼 소수 | 원 단위 정수로. **0.5 는 올린다** — 파이썬 기본 `round()` 는 은행가 반올림이라 내려간다 |

### 이미지

응답이 주는 주소는 **1120px 원본 PNG, 한 장에 845KB** 다. 그리드에 48장이면
40MB 라 그대로 쓰면 안 된다. 네이버 CDN 리사이즈 파라미터를 쓴다 (실측).

| 파라미터 | 크기 | 용량 | 쓰는 곳 |
|---|---|---|---|
| `?type=s_webp` | 180px | 7KB | 안 씀 (레티나에서 흐리다) |
| `?type=m_webp` | 525px | 32KB | **그리드 썸네일** |
| `?type=l_webp` | 1120px | 76KB | **눌러서 여는 원본** |

**`referrerpolicy="no-referrer"` 가 반드시 있어야 한다.** 네이버 CDN 은 Referer
가 KREAM 도메인이 아니면 403 + `text/html` 을 주고, 그러면 Chrome 이
`ERR_BLOCKED_BY_ORB` 로 막아 **이미지가 한 장도 안 뜬다.** `dorumugs.github.io`
에서도 똑같이 403 이므로 배포해도 깨졌을 문제다. Referer 를 안 보내면 200 이다.

### 저장

| 파일 | 내용 |
|---|---|
| `data/pokemon/kream.json.gz` | 응답 원본. `mtime=0` 고정 (206KB) |
| `assets/pokemon/krw.json` | 화면용. 441KB · gzip 147KB |

시계열을 누적하지 않는다. 응답이 이미 31일 이력을 들고 오고, 그 이상은 화면이
쓰지 않는다.

## 3. 글로벌과 섞지 않는다

**두 데이터는 조인되지 않는다.** 조인해서도 안 된다.

| | 글로벌 (TCGdex) | 국내 (KREAM) |
|---|---|---|
| 언어판 | 영문 | 일어판 830 · 한글판 54 · 영문판 14 |
| 상태 | raw 가 기본, 비싼 카드에만 PSA 10 | 전부 **PSA 10 등급** |
| 세트 코드 | `base1`, `sv3` … | `S8A`, `SV2A`, `PROMO` … |
| 수 | 17,683장 | 899종 |

`style_code` 앞자리가 우리 세트 id 와 겹치는 건 899종 중 34종뿐이고, 그마저
영문 `sv3` 와 일본판 `SV3` 는 다른 상품이다. **등급이 다르므로 같은 카드라도
값이 몇 배로 벌어진다.** 나란히 놓고 빼면 거짓말이 된다.

그래서 **탭으로 가른다.** 두 탭 위에 경고 문구를 항상 띄운다.

### 탭을 숨길 때 `hidden` 만 믿지 말 것

테마 `main.css` 에 HTML5 리셋 `article, aside, …, section { display: block }` 이
있다. 이게 브라우저 기본 `[hidden] { display: none }` 을 **이긴다.** 그대로 두면
`hidden` 속성은 걸려 있는데 화면에는 두 탭이 세로로 겹쳐 나온다.

`pokemon.css` 에 `.pk-app [hidden] { display: none }` 을 넣어 되돌린다.

검증도 같이 고쳐야 한다. `element.hidden` 은 **속성만** 보므로 이 상황에서
통과해 버린다. `getComputedStyle(el).display === 'none'` 을 봐야 한다. 실제로
속성만 보는 검사로 33개를 통과시키고 배포했다가 스크린샷에서 잡았다.

## 4. 화면

`/dashboard/pokemon/` 에 탭 둘(글로벌·국내). 각 탭은 카드형·표형을 오간다.

### 국내 탭

| 구역 | 내용 |
|---|---|
| 통계 타일 | 상품 수 · 중앙값 · 최고가 · 30일 거래 1건 이하 종 수 |
| 시장 추이 | 31일 차트. 중앙값은 선, 거래건수는 옅은 막대. 문지르면 그날 값 |
| 검색·필터 | 이름(한/영)·품번 검색, 언어판, 거래 2건 이상만, 정렬 6종 |
| 그리드 | 사진·한글명·영문명·언어·품번·현재가·30일 변동·고저·거래건수 |

차트는 외부 라이브러리 없이 SVG 를 직접 그린다. `viewBox` 로 그려 폭에 맞춰
늘어나므로 390px 에서도 넘치지 않는다.

`krw.json` 이 gzip 147KB 라 **탭을 처음 열 때만 받는다.** 글로벌만 보는
사람에게 국내 데이터를 지울 이유가 없다.

### 화면에 반드시 적는 한계

숫자를 크게 띄우면 사람은 그걸 믿는다. 믿을 근거가 얼마나 얇은지 같이 적는다.

- PSA 10 등급 기준이다. 글로벌의 raw 가격과 빼면 안 되고, 글로벌 쪽 PSA 10 과 견줘야 한다 (비교 탭이 그것만 계산한다).
- 899종 중 830종이 일어판이다. 한글판은 54종뿐이다.
- **899종 중 404종은 30일 거래가 1건 이하다.** 한 사람이 한 번 판 값이 그대로
  "시세" 가 된다.
- 변동률의 `—` 는 0% 가 아니라 "모른다" 다.
- KREAM 에 올라온 것만이다. 번개장터·중고나라는 안 잡힌다.
- 수수료·감정료가 빠진 값이다.

## 5. 곁다리로 고친 것 — 사진 없는 카드

지난 커밋이 `build_pokemon.py` 와 `app.js` 는 고쳤는데 **`assets/pokemon/cards.json`
을 다시 굽지 않고 커밋했다.** 그래서 화면이 읽는 파일에 `tcg_pid` 컬럼이 없었고,
TCGplayer 사진 보강이 **라이브에서 전혀 작동하지 않고 있었다.** 588장이 계속
"이미지 없음" 이었다.

다시 구우면서 세 번째 출처를 붙였다.

| 순서 | 출처 | 담당 |
|---|---|---|
| 1 | TCGdex | 대부분 |
| 2 | TCGplayer productId | TCGdex 가 안 주는 카드 |
| 3 | **pokemontcg.io** | 위 둘 다 없는 세트 |

3순위는 경로 규칙을 화면에 심지 않는다. 수집기가 **HEAD 로 존재를 확인한
카드만** `data/pokemon/art.json` 에 적고, 화면은 그 표에 있는 것만 그린다.
규칙으로 만들면 없는 이미지를 요청해 404 를 흘린다.

결과: 318장 복구. 세 출처를 다 뒤져도 없는 카드는 **39장**만 남는다
(My First Battle 34 · Poké Card Creator Pack 5). 이 숫자를 화면에 적는다.

## 5-2. 글로벌에도 등급 시세를 붙였다

"국내는 PSA 10 인데 글로벌은 왜 등급이 없나"는 질문에서 출발했다. 답은
**그 데이터에 등급 축이 아예 없어서**였다 — TCGdex·TCGplayer·tcgcsv 모두
인쇄 판본(`Normal`/`Holofoil`/`Reverse Holofoil`)으로만 나눈다.

### 후보를 다 두들겨 본 결과 (2026-08-08)

| 출처 | 등급별 가격 | 접근 | 판정 |
|---|---|---|---|
| PSA 공식 낙찰가(APR) | ✅ | 카드 상세가 **로그인 벽** | 쓰지 않음 |
| PriceCharting | ✅ Ungraded~PSA10 6단계 + 거래빈도 | **API 유료 구독 전용** | 페이지를 긁으면 그 회사가 파는 상품을 그대로 대체한다. 쓰지 않음 |
| PokemonPriceTracker | ✅ PSA/BGS/CGC/SGC/TAG/ACE | **무료 키**, 상용 라이선스 포함 | **채택** |

### 크레딧 산수

카드 1장 = **2 크레딧**(카드 1 + eBay 1). 무료 등급은 하루 100 → **50장**.
전량 덤프(`/export`)는 Business($99/월) 이상 전용이라 못 쓴다.

| 대상 | 카드 수 | 무료(50장/일) 주기 |
|---|---|---|
| raw $500 이상 | 79 | 2일 |
| raw $200 이상 | 270 | 5일 |
| **raw $100 이상 (기본값)** | **541** | **11일** |
| raw $20 이상 | 1,854 | 37일 |

$20 넘는 카드는 **전부 `tcgPlayerId` 가 있어 조인이 100%** 다(1,854/1,854).

**무료로 충분하다.** 등급 시장은 거래가 극단적으로 얇다 — 베이스셋 리자몽
PSA 10 이 최근 1년에 **1건** 팔렸다. 11일 주기가 데이터 갱신 속도보다 빠르다.
더 넓게·더 자주 원하면 $9.99/월(하루 1만장)로 올리면 되고 코드는 그대로다.

### 숫자를 어떻게 다루나

값은 `smartMarketPrice`(기간 잘라 가중한 값)를 쓰고 없으면 중앙값으로 물러선다.
중앙값만 쓰면 1년 전 한 건이 오늘 시세인 척한다.

**값과 표본을 절대 떼어놓지 않는다.** 화면에 가격을 적을 때 항상
`건수 · 마지막 거래일`을 붙인다. 1건짜리는 시세가 아니라 사례 하나다.

raw 대비 배수도 같이 싣는다. 지금 모인 43장 기준 **중앙값 8.6배, 최대 40.7배**
(피카츄 스타 raw $3,200 → PSA 10 $99,375). 이 배수가 곧 감정료·대기시간·등급이
안 나올 위험의 값이다.

### 남은 것

국내 탭이 PSA 10 원화, 글로벌 탭이 PSA 10 달러가 되었으므로 이제 같은 기준으로
비교할 수 있다. 화면은 5-3 절의 비교 탭으로 붙였다.

## 5-3. 비교 탭 — 자동 매칭은 하지 않는다

글로벌에 PSA 10 이 생기자 **경고 문구가 거짓이 되었다.** "글로벌은 등급 없는
raw" 는 더 이상 사실이 아니다. 실제 차이는 이제 **언어판**(영문 vs 일본)과
**등급 커버리지**(글로벌은 비싼 카드에만 PSA 10)다. 문구를 다시 썼다.

### 왜 기계가 짝지어 주면 안 되나

KREAM 한글 상품명에서 포켓몬 종 이름은 **899종 중 801종(89%)** 이 잡힌다.
그래서 이을 수 있을 것처럼 보이지만, 실제로는 이렇다.

| 종 | KREAM | 글로벌 |
|---|---|---|
| 피카츄 | 112종 | 98장 |
| 리자몽 | 45종 | 76장 |

**종 이름 하나에 글로벌 카드가 1장뿐인 경우는 0건이고, 10장 이상이 206종이다.**
"리자몽" 으로 이으면 베이스셋 카드와 최신 일본판 SAR 이 묶인다. 그건 비교가
아니라 오답이다.

그래서 **고르는 건 사람이 한다.** 검색어 하나로 양쪽을 동시에 검색해 좌우
**표**로 놓고, 사용자가 한 줄씩 고르면 그 둘만 같은 통화로 환산해 **항목별 표**로
나란히 놓는다.

| 항목 | 글로벌 · 영문판 | 국내 · KREAM | 차이 |
|---|---|---|---|
| 카드 · 세트 · 언어판 | | | |
| raw 현재가 | | — | 국내는 raw 를 안 판다 |
| **PSA 10** | | | **여기만 계산한다** |
| PSA 9 · 표본 · 30일 고저 | | | |

차이 칸은 **PSA 10 행에만** 채운다. 나머지는 비워 둔다 — 빈칸이 잘못된 뺄셈보다
낫다. 표는 `.pk-table-wrap` 안에 넣어 390px 에서 자체 스크롤한다.

국내 30일 고가와 저가가 같으면 "거래 한 건" 이라고 적는다. 그 경우 그 값은
시세가 아니라 사례 하나다.

### 통화 넷과 김치 프리미엄

**환율은 USD 기준 하나만 들고 다닌다.** 모든 값을 달러로 모은 뒤 원·유로·엔으로
편다. 통화쌍을 여러 개 받으면 교차 환산이 서로 어긋난다.

`collect_fx.py` 는 네 값 중 **하나라도 범위를 벗어나면 통째로 버린다** — 일부만
맞는 환율표는 화면에서 어느 칸이 틀렸는지 알 수 없어 더 위험하다.

| | USD 1 당 정상 범위 |
|---|---|
| KRW | 500 ~ 3,000 |
| EUR | 0.5 ~ 2.0 |
| JPY | 60 ~ 400 |

**유로가 두 종류라는 걸 화면이 구분해야 한다.** 표의 `유럽 실거래` 는
Cardmarket 의 **실제 체결가**(카드의 99%에 있다)고, 나머지 유로는 달러를 환산한
값이다. 실제로 크게 벌어진다 — 베이스셋 리자몽이 Cardmarket €403 인데 달러
환산은 €709 다. 그 차이 자체가 유럽 시장의 특성이라 뭉개면 안 된다.

목록은 원래 통화 + 사용자가 고른 통화 **둘만** 보인다. 넷을 다 넣으면 표가
못 읽힌다. 비교표에서만 넷을 다 편다.

### 김치 프리미엄

국내가 해외보다 비싼 정도를 `김치 프리미엄`, 싼 경우를 `역프리미엄` 으로 적는다.
코인 시장에서 굳은 말이라 뜻이 바로 통하고, 이미 쓴 김프 글과 이어진다.

**이 폭이 그대로 차익이 아니라는 걸 같이 적는다.** 수수료·감정료·관세·환전비용이
다 빠져 있다. 코인 김프가 그렇듯 마찰비용이 프리미엄보다 크면 남는 게 없다.

### 가격대로 찾기

이름이 달라도 값이 비슷하면 견줄 거리가 된다. 금액과 허용범위(±10~50%)를 받아
양쪽에서 그 구간의 카드를 찾는다.

**기준은 PSA 10 이고, PSA 10 값이 없는 카드는 아예 뺀다.** raw 를 섞으면 등급이
다른 것끼리 걸려서 "비슷한 가격" 이라는 말 자체가 무의미해진다.

### 뺄셈을 언제 거부하는가

**글로벌 카드에 PSA 10 값이 없으면 계산하지 않는다.** raw 와 PSA 10 을 빼면
나오는 건 나라 차이가 아니라 등급 프리미엄이라, 그대로 보여주면 독자가
한일 스프레드로 오해한다. 그 경우 "PSA 10 값이 없어 뺄 수 없습니다" 라고 적고
이유까지 화면에 쓴다.

계산할 때도 세 가지를 항상 붙인다 — 환산에 쓴 **환율과 기준일**, "영문판과
일본판은 다른 카드", "수수료·감정료·관세는 빠져 있음".

### 환율

`open.er-api.com` (키 불필요, 기준일 제공). `data/pokemon/fx.json` 에 저장하고
`meta.json` 에 실어 화면이 쓴다. 실패하거나 값이 이상하면 기존 값을 유지한다 —
조용히 틀린 환율로 덮어쓰지 않는다.

### 알아둘 것

KREAM 에도 **영문판 상품이 14종** 있고 품번이 `BS4/102_EN` 처럼 영문 세트를
그대로 쓴다. 이쪽은 like-for-like 비교가 가장 defensible 하다. 목록에 언어판을
항상 표시해 두었으므로 사용자가 골라낼 수 있다.


## 5-4. PSA 10 통합 표 — 만들었다가 걷어냈다

"글로벌과 국내를 한 표로" 라는 요청에 통합 표를 만들었다. 원칙은 옳았다 —
*한 표에는 한 가지 값만* 넣어야 하므로 PSA 10 만 담았다. 그런데 **핵심 기능이
성립하지 않아 걷어냈다.**

김치 프리미엄을 내려면 글로벌 PSA 10 줄과 국내 줄을 짝지어야 하는데,

| | 수 |
|---|---|
| 글로벌 PSA 10 줄 | 43 |
| 국내 영문판 줄 (같은 언어판이라 그나마 견줄 만한 것) | **14** |

이 43 × 14 조합 중 **실제로 같은 카드인 것**만 유효하다. 나머지 845개 국내
줄은 일어판·한글판이라 영문판과 다른 물건이다.

게다가 표본이 이렇다.

| | 표본 1건 이하 |
|---|---|
| 글로벌 줄 | 6 / 43 (14%) |
| 국내 줄 | **404 / 859 (47%)** |

**한 번 팔린 값과 한 번 팔린 값을 빼서 소수점 한 자리 퍼센트를 내놓고 있었다.**
이 대시보드가 처음부터 경계해 온 가짜 정밀도를, 탭 하나를 통째로 만들어서
하고 있었던 셈이다.

### 남긴 것

이번 작업의 진짜 수확인 **언어판 격차 40줄은 전부 국내 데이터**라 통합 표가
필요 없었다. 국내 탭으로 옮겼다.

| | 어디로 |
|---|---|
| 언어판 묶기 · 격차 | **국내 탭**. 품번에서 언어 접미사만 떼는 하드 키 |
| 4통화 표시 | **국내 탭**. 원화 + 고른 통화 하나 |
| 글로벌 raw vs PSA 10 | **글로벌 탭 유지.** 같은 카드·같은 시장의 두 등급이라 비교가 성립한다 |
| 통합 표 · 김치 프리미엄 · 가격대 검색 | **삭제** |

김치 프리미엄은 조건이 갖춰지면 되살릴 수 있다 — 국내 영문판이 늘거나
글로벌 PSA 10 커버리지가 541장까지 차서 같은 카드가 양쪽에 잡힐 때다.

## 5-5. 사진 네 번째 출처와 보기 전환

### 위키가 마지막 그물이다

셋을 다 뒤져도 39장이 남았다 (My First Battle 34, Poké Card Creator Pack 5).
아주 오래됐거나 비매품인 세트라 **상업 시세 사이트가 안 다룬다.** 이런 건
위키가 다룬다 — Bulbagarden Archives 에서 33장을 찾았다.

파일 이름 규칙 (실측)

| 세트 | 규칙 |
|---|---|
| My First Battle | `{이름}MyFirstBattle.jpg` |
| Poké Card Creator Pack | `{이름}CreatorContest{번호}.png` |

**썸네일 URL 을 손으로 만들면 404 다.** MediaWiki 가 요청받을 때 생성하므로
API 에 `iiurlwidth=245` 를 줘서 `thumburl` 을 받아야 한다. 원본이 416KB, 썸네일이
23KB 로 카드 비율(245×342)에 딱 맞는다.

**여기도 `referrerpolicy="no-referrer"` 가 필요하다.** KREAM 때와 똑같이 Referer
가 남의 도메인이면 막고 Chrome 이 `ERR_BLOCKED_BY_ORB` 로 버린다. 이제 모든
`<img>` 에 붙어 있다.

결과: 사진이 아예 없는 카드가 **39장 → 6장** (기본 에너지 4·포션·스위치).

### 안 세던 것: 경로는 있는데 파일이 없는 카드

여기까지 센 것은 전부 **"경로가 아예 없는 카드"** 였다. 그런데 TCGdex 는
**경로를 주면서 파일이 없는** 카드가 있다. 화면에서는 `onerror` 가 조용히
숨겨 '이미지 없음' 으로만 보이고 집계에는 안 잡힌다. 사용자가 "블래키가
없다" 고 알려주기 전까지 몰랐다.

TCGdex 경로를 쓰는 **17,179장을 전수로 두들겨** 90장을 찾았다.

| 세트 | 깨진 수 |
|---|---|
| `ecard2` Aquapolis | 40 |
| `ecard3` Skyridge | 32 |
| sm6 · dc1 · pop6 · sm2 · pl2 · cel25 · xy8 | 18 |

하필 e-Card 시절 `H` 번호 홀로들이라 **블래키·후딘·마기라스·스이쿤·아쿠스타의
대표 카드**가 거기 몰려 있었다. 전부 pokemontcg.io 에 있어서 90장 다 메웠다.

**화면의 우선순위를 뒤집었다.** 원래 `TCGdex 규칙 → … → art.json` 순서였는데,
화면은 경로를 **세트 단위**(`series[set]`)로 만들기 때문에 카드 하나만
깨져도 끌 방법이 없었다. 이제 `art.json`(이 카드에 대해 실제로 열리는 것을
확인한 주소)이 **0순위**다. 규칙보다 확인된 사실이 먼저다.

`--verify-tcgdex` 로 다시 전수 검사할 수 있다. 느리므로 매일이 아니라 가끔
돌린다. 결과는 `data/pokemon/art_broken.json` 에 남는다 — 수집기가 매일 원본을
다시 받아 경로를 되살리므로 따로 기억해야 한다.

### 카드형과 표형

두 탭 다 `카드형 / 표형` 을 오간다. 표형에도 **44px 썸네일**을 넣는다 —
이름만으로는 같은 포켓몬이 수십 장이라 어떤 카드인지 알 수 없다.

표는 `.pk-table-wrap` 안에서만 가로로 넘치므로 390px 에서 페이지가 안 깨진다.


## 5-6. 두 시장 상호 안내 — 만들었다가 걷어냈다

"글로벌에서 국내에도 있는 걸 알려달라" 는 요청이었다. 카드 단위로는 못 하므로
종(species) 단위로 `국내 리자몽 48종 →` 을 카드마다 붙였다. **그리고 걷어냈다.**

재보니 이랬다.

| | |
|---|---|
| 배지가 붙는 카드 | 5,180장 |
| 서로 다른 문구 | **258개** |
| 같은 문구가 반복되는 평균 | **20장** |
| 종 안에서 문구가 달라지는 경우 | **0건** |

`국내 리자몽 48종` 이 리자몽 카드 76장 **전부에 똑같이** 붙는다. 카드마다
달라지는 게 하나도 없으니 이건 카드의 속성이 아니라 **검색어의 속성**이다.
카드 단위 배지의 옷을 입고 있을 뿐이었다.

결과 줄 하나로 옮기면 잡음은 사라지지만, 그래도 남는 값은 "탭 바꾸고 이름
치기" 한 번을 아껴 주는 정도다. 그 대가로 데이터 파일(`xref.json`)·빌드
단계·두 화면의 코드·검사 여섯 개를 매일 도는 파이프라인에 얹어야 했다.
**값이 비용을 못 넘어서 전부 지웠다.**

교훈: 만들기 전에 **"이 값이 카드마다 달라지는가"** 를 먼저 물었어야 했다.
같은 세션에서 PSA 10 탭도 같은 이유로 걷어냈다 — 그때는 표본이 1건인
숫자였고, 이번엔 20장에 반복되는 문구였다.

### 하드코딩한 숫자는 곧 거짓이 된다

이 과정에서 본문에 박아둔 숫자가 하루 만에 틀어져 있는 걸 발견했다.

| 문구 | 실제 |
|---|---|
| 899종 | 903종 |
| 404종 | 408종 |
| 830종이 일어판 | 831종 |

매일 갱신되는 대시보드에서 본문에 숫자를 박으면 **다음 실행에 거짓이 된다.**
`data-live` 자리표시를 두고 화면이 데이터에서 채우도록 바꿨다. 검사에도
"자리표시가 `—` 로 남아 있지 않은가" 를 넣었다.

## 7. 검증

```shell
python3 -m unittest discover -s tests
```

433개 통과. 새로 붙인 것은 `test_kream_api`(23) · `test_build_kream`(13) ·
`test_ptcg_api`(13) · `test_ppt_api`(21). 고정 응답은 `tests/fixtures/kream_chart.json` 이다 —
KREAM 은 공식 API 가 아니라 화면이 바뀌면 조용히 깨지므로 실제 응답 표본을
박아 둔다.

화면은 헤드리스로 몰아 60개 항목을 확인했다. 390px·1280px 양쪽에서

- 가로 오버플로 없음 (`scrollWidth` 실측 + 넘치는 개별 요소 탐색)
- 탭 전환 · 국내 데이터 지연 로딩 · 차트 31점 렌더
- 한글/영문 검색이 같은 53종을 찾는다 · 정렬 · 거래 필터(899→495)
- 변동률 없는 상품이 `—` 로 나온다
- **사진 세 출처가 실제로 뜬다** (`naturalWidth` 로 확인, 화면 안에 든 것만)
- 등급 시세 줄에 **값과 함께 건수·거래일·raw 대비 배수**가 나온다
- 카드형↔표형 전환, 표형에도 사진이 뜬다
- 언어판 묶기가 899종을 859줄로 접고 격차를 보여준다
