# 학군 지도 — 설계

작성일: 2026-07-27
상태: 승인됨
선행 문서: `2026-07-26-real-estate-dashboard-ui-design.md` (실거래 대시보드)

## 배경

`/real-estate/` 허브의 두 번째 도구다. 실거래 대시보드가 "어디가 얼마인가"를
답했고, 이건 "이 학교 근처 집은 얼마인가"를 답한다.

바탕이 된 글이 이미 다섯 편 있다 (`finance` 카테고리):

- 학군지 시리즈 3편 — 대치·목동·중계 / 1기신도시 / 신흥도심.
  학원가를 기준으로 **단지별 실거래가를 비교**하는 글이다.
- 중학교 코스 2편 — 일반중·국제중·사립중 프레임, 그리고 실제 학교 지도.
  "이름값이 아니라 우리 집 통학·성향으로 읽는 학교 지도"를 표방하고
  마지막 절이 **"위치로 역산하기"** 다.

두 시리즈 모두 학교와 시세를 같이 놓고 본다. 이 도구는 그 작업을 손으로 하지
않게 만든다.

## 목표

`/real-estate/schools/` 에서 서울·경기 초·중·고를 지도에 올리고, 학교를 누르면
그 학교가 속한 법정동의 아파트 실거래 시세를 보여준다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 핵심 질문 | **이 학교 근처 집은 얼마인가** (역산) |
| 학교 범위 | 초·중·고 전부, 학교급 필터로 전환 |
| 지역 범위 | **서울·경기만** |
| '근처'의 정의 | **같은 법정동** (지오코딩 없음) |
| 지도 | 실거래 대시보드의 `map.svg` 를 그대로 재사용 |
| 진입 흐름 | 구를 먼저 고르고 → 그 구의 학교를 본다 |

### 서울·경기만 하는 이유

실거래 데이터가 서울·경기뿐이다. 다른 지역 학교를 올려도 옆에 붙일 시세가 없다.
수집 단계에서 시도교육청 코드로 걸러 나머지는 저장조차 하지 않는다.

### '같은 법정동' 으로 정한 이유

진짜 반경(500m/1km)을 재려면 단지 좌표가 필요한데, **단지 마스터에는 좌표가
없다** (PNU 와 주소만 있다). 전국 아파트 단지 좌표를 한 번에 주는 공개 데이터셋도
없어서, 5천~2만 건을 지오코딩 API 로 변환해 캐시해야 한다 — 키를 하나 더 신청하고
1회성 배치를 만드는 비용이다.

반면 **좌표 없이 되는 길이 이미 있다.** 학교 위치 데이터에 지번주소가 있고,
구별 JSON 의 단지에는 `dong`(법정동) 필드가 이미 들어 있다. 둘을 법정동으로 맞추면
지오코딩이 필요 없다. 실측으로 확인한 조인 경로다:

```
regions.dong_code('11680', '대치동') -> 1168010600
regions.dong_code('11470', '목동')   -> 1147010200
regions.dong_code('41135', '서현동') -> 4113510500
```

대치동처럼 넓은 동은 '근처'라기엔 성기다. 그 사실을 화면에 명시해 오해를 막고,
반경이 필요해지면 그때 좌표를 붙인다. 설계를 반경으로 교체하기 쉬운 모양으로
잡아 둔다 — 근접 판정을 한 함수에 가둔다.

## 데이터

### 출처와 접근 권한

| 데이터셋 | 엔드포인트 | 쓰임 |
|---|---|---|
| 전국초중등학교위치표준데이터 | `tn_pubr_public_elesch_mskul_lc_api` | 학교 위치 — **필수** |
| 전국중학교학교군표준데이터 | `tn_pubr_public_mskul_atndskl_zn_api` | 2차 |
| 전국학교학구도연계정보표준데이터 | `tn_pubr_public_schul_atndskl_zn_drw_lnkinfo_api` | 2차 |

**2026-07-27 실측: 위 셋과 고교 비평준화까지 네 개를 시험했고, 모두 엔드포인트는
존재하지만 현재 키가 등록돼 있지 않다** (`resultCode 30 = SERVICE KEY IS NOT
REGISTERED`. 존재하지 않는 서비스는 `12` 를 돌려주므로 둘을 구분할 수 있다).
data.go.kr 에서 데이터셋별로 활용신청이 필요하다. 표준데이터는 보통 자동승인이다.

**구현은 위치 데이터 하나만 있으면 시작할 수 있다.** 나머지 둘은 1차 범위 밖이다.

### 학구도 데이터로는 배정을 못 푼다

`전국학교학구도연계정보표준데이터` 를 확인한 결과 필드가 학구ID·학교ID·학교명·
학교급·교육청코드뿐이고 **경계 도형이 없다.** 주소나 행정동 코드로 통학구역을
매핑해 주지 않는다. "이 아파트는 어느 학교로 배정되나"를 정확히 답할 수 없는
이유이고, 역산 방향을 고른 근거이기도 하다.

### 위치 데이터에 없는 것

학교명·학교급·설립구분(공/사립)·본분교·운영상태·지번주소·도로명주소·교육청·
위도·경도가 전부다. **진학률도 학업성취도도 없다.** 학군의 "질"은 기존 글이
답하고, 이 도구는 위치와 시세를 답한다. 화면이 이걸 넘어서는 인상을 주면 안 된다.

## 아키텍처

```
[학교위치 표준데이터 API]              scripts/collect_schools.py
  서울·경기 초·중·고               →  data/schools.csv.gz
                                          │
data/geo/projection.json ──────────────┤  scripts/build_schools.py
  (build_geo.py 가 내보낸 투영 파라미터)  │  위경도 → SVG 좌표, 법정동 조인
                                          ▼
                        assets/realestate/schools/{sgg}.json
                        assets/realestate/schools/index.json
                                          │
                                          ▼
              _pages/real-estate-schools.md  →  /real-estate/schools/
```

원본 → 집계 → 표현 3단 분리는 실거래 때와 같다.

### 투영 공유 — 이 설계의 유일한 까다로운 지점

학교 점을 기존 지도에 얹으려면 **`build_geo.py` 와 완전히 같은 투영**을 써야 한다.
지금 `build_geo.py` 의 `project()` 는 `min_lon`, `max_lat`, `k`, `span_x`, `span_y` 를
내부에서 계산하고 버린다.

`data/geo/projection.json` 으로 내보내도록 고친다.

```json
{"min_lon": 126.xxx, "max_lat": 38.xxx, "k": 0.79xxx,
 "span_x": 1.xxx, "span_y": 1.xxx, "width": 1000.0, "height": 1201.x}
```

`build_schools.py` 는 이 파일만 읽어 같은 식으로 변환한다.

```
x = (lon - min_lon) * k / span_x * width
y = (max_lat - lat) / span_y * height
```

파라미터를 각자 계산하면 경계 데이터나 `--eps` 를 갱신할 때 학교 점이 조용히
어긋난다. 한 곳에서만 정의하고 나머지는 읽기만 한다.

`build_geo.py` 변경은 파일 하나를 더 쓰는 것뿐이다. **`map.svg` 는 재생성해도
바이트가 동일해야 한다** — 회귀 확인 항목이다.

### 법정동 조인

학교 지번주소에서 시군구와 읍면동 이름을 뽑아 `regions.dong_code()` 로 10자리
법정동 코드를 만든다. 구별 JSON 의 단지 `dong` 도 같은 함수로 코드화해 맞춘다.
이름 문자열로 직접 비교하지 않는다 — 같은 이름의 동이 다른 구에 있다.

조인 실패율을 로그로 남기고 **10% 를 넘으면 빌드를 실패시킨다.** 실거래 때
화성시 단지 마스터가 통째로 비어 있는 걸 늦게 발견한 전례가 있다.

## 출력 포맷

### `assets/realestate/schools/index.json`

구별 학교 수와 학교급 분포. 지도에서 구를 칠하는 데 쓴다.

```json
{"generated": "2026-07-27",
 "sgg": {"11680": {"name": "강남구", "n": {"초": 33, "중": 24, "고": 21}}}}
```

### `assets/realestate/schools/{sgg}.json`

구 하나의 학교 목록. 구를 처음 누를 때 받는다.

```json
{"sgg": "11680",
 "schools": [
   {"id": "...", "name": "대치중학교", "lvl": "중", "found": "공립",
    "dong": "대치동", "dong_cd": "1168010600",
    "addr": "서울특별시 강남구 대치동 ...",
    "x": 512.3, "y": 641.8}
 ]}
```

`x`/`y` 는 `map.svg` 의 viewBox 좌표다. 소수점 한 자리로 고정해 결정론을 지킨다.

## 화면

```
[ 서울 | 경기 | 전체 ]        [초] [중] [고]   [공립/사립]
┌─────────────────┬──────────────────┐
│   지도           │  대치중학교        │
│  (구 채색 +      │  공립 · 중학교     │
│   학교 점)       │  강남구 대치동      │
│                 │  ──────────────   │
│                 │  대치동 아파트 시세  │
└─────────────────┴──────────────────┘
        같은 법정동 단지 표 (전체 폭)
```

- 구를 고르기 전에는 구별 학교 수로 지도를 칠하고, 학교 점은 그리지 않는다.
  서울·경기 4천 개를 한 번에 뿌리면 눌러볼 수 없다.
- 구를 누르면 그 구의 학교만 점으로 뜬다. 학교급 필터가 점을 걸러낸다.
- 학교를 누르면 오른쪽에 학교 정보, 아래에 그 법정동 단지 표가 나온다.
- 단지 표는 실거래 대시보드의 구별 JSON 을 그대로 읽는다. 새 집계가 없다.

### 오해를 막는 문구

화면에 **"같은 법정동 기준입니다. 실제 배정 학교는 통학구역에 따라 다릅니다"** 를
상시 표시한다. 이걸 안 달면 배정표로 읽힌다.

국제중·사립중은 배정이 아니라 지원이라 '근처'의 의미가 다르다. 설립구분을 함께
보여줘 구분되게 한다.

### 모바일 390px

실거래 대시보드와 같다. 2단이 세로로 접히고 표는 `overflow-x: auto` 안에 들어간다.
`_dev/tools/check_mobile.py` 로 `[click]`·`[tooltip]` 양쪽을 확인한다.

### URL 파라미터

`/real-estate/schools/?sgg=11680&lvl=중&school=<학교ID>`

글에서 특정 학교 화면을 바로 가리킬 수 있게 한다. 실거래 대시보드와 같은 규칙이고,
잘못된 값은 무시하고 기본값으로 떨어진다.

## 재사용

`map.js`, `palette.js`, `data.js`, `dashboard.css` 를 그대로 쓴다. 새로 만드는 것은
학교 점 레이어와 패널 렌더러뿐이다.

실거래 대시보드의 동작은 바뀌지 않는다. `build_geo.py` 만 파일 하나를 더 쓰도록
바뀌고, 그 결과 `map.svg` 가 재생성되지만 **바이트가 같아야 한다.**

## 색

`palette.js` 를 그대로 쓴다. 새 색을 만들지 않는다.

- 구 채색(학교 수): 순차 램프
- 학교 점: 학교급 3종을 범주형 앞 세 칸(파랑·주황·아쿠아)으로. 발산 램프의
  중립과 겹치지 않는다
- 점 크기는 8px 이상, 선택된 점은 표면색 링으로 둘러 겹침에서 구분한다

학교급은 점 색만으로 구분하지 않는다 — 범례를 상시 두고, 툴팁에 학교급을 글자로
넣는다.

## 검증

- **투영 일치**: 알려진 좌표(예: 서울시청 위경도)를 두 스크립트가 같은 SVG 좌표로
  변환하는지. `map.svg` 재생성 후 바이트 동일
- **법정동 조인**: 실패율 10% 미만. 대치동·목동·중계동·서현동은 반드시 성공
- **학교급 필터**: 초·중·고 각각 점 개수가 `index.json` 과 일치
- **결정론**: 같은 입력으로 두 번 빌드해 JSON 바이트 동일
- **크기 예산**: 구별 학교 JSON 100KB 이하
- **모바일**: 390px 에서 `scrollWidth <= 390`
- **API 실패**: 키 미등록(`resultCode 30`) 을 명확한 메시지로 안내하고 정상 종료
