# 재개발 대시보드 — 자치구 다중 선택

2026-08-07. `/real-estate/redevelopment/` 의 지도 선택을 단수에서 복수로 바꾼다.
데이터 파이프라인은 건드리지 않는다 — 화면단(`redev-app.js`·`map.js`·`redev.css`)만
바뀐다. 데이터 쪽 배경은 `2026-07-31-redevelopment-design.md` 를 보라.

## 왜

구를 고르면 그 구만 보이고, 다른 구를 누르면 앞의 것이 사라졌다. 그래서
"강남·서초·송파 중 대지지분이 큰 단지"처럼 **구를 가로지르는 질문에 답할 수
없었다.** 지도는 25개 구를 한눈에 보여주는데 표는 한 구씩만 보여주는 것도
어긋난다.

한 번 고른 구를 되돌릴 방법이 없다는 문제도 함께 있었다. 실거래·학군 두
페이지에는 `← 목록으로` 버튼이 있는데 재개발에만 없다.

## 무엇을

### 상태

`state.sgg`(단수) → `state.sggs`(배열). **선택한 순서를 유지한다** — 진행 단계
표를 그 순서로 쌓기 때문이다.

`map.js` 의 `setSelected(code)` 를 `setSelected(codes)` 로 넓힌다. `null`·단일
코드·배열을 모두 받아, 실거래 대시보드(`app.js`)는 고치지 않아도 되게 한다.
내부는 `Set` 으로 바꾸고 72개 path 에 `is-selected` 를 토글한다.

### 조작

| 동작 | 결과 |
|---|---|
| 지도에서 안 고른 구 클릭 | 선택에 **추가** |
| 지도에서 이미 고른 구 클릭 | 선택에서 **제거** (토글) |
| 칩의 `×` | 그 구만 제거 |
| `모두 지우기` | 전부 제거 |
| 빈 상태 요약 표의 구 이름 클릭 | 선택에 추가 |
| 모드 탭 (노후 단지 / 진행 단계 / 단계별 프리미엄) | **전부 해제**, 빈 상태로 |
| 지역 탭 (서울 / 경기) | 전부 해제 (기존 동작 유지) |

`← 목록으로` 버튼은 넣지 않는다. `모두 지우기` 와 모드 탭이 같은 일을 한다.

### 선택 칩

`.re-panel-meta` 아래 `.re-picks`. **구가 2곳 이상일 때만** 보인다. 하나일 때는
제목이 곧 구 이름이고 지도 재클릭으로 풀 수 있어 칩이 군더더기다.

### 표

`구` 열을 맨 앞에 넣는다 — **2곳 이상 골랐을 때만**. 한 구만 볼 때는 모든 행의
값이 같아 쓸모가 없고, 노후 단지 표는 이미 11열이라 390px 에서 가로 스크롤이
길어지기만 한다.

합치는 순서:

- **노후 단지** — 합친 뒤 연차 내림차순. 안내문의 "오래된 순으로 정렬했습니다"가
  여러 구에서도 참이어야 한다.
- **진행 단계** — 선택한 구 순서대로, 구 안에서는 원래 순서.

### 빈 상태 = 지역 구 요약 표

선택이 0개면 `redev.json` 의 `sgg` 블록만으로 `구 / 노후 단지 / 정비사업장` 표를
그린다. **추가 요청이 없다** — 이미 받아 둔 집계다. 지금 보는 모드의 값(노후 단지
수 또는 사업장 수) 내림차순으로 세운다.

예외: 경기 + 진행 단계는 표를 그리지 않는다. 43개 시군구가 전부 0이라 표를
그리면 "자료가 있는데 0"으로 읽힌다. 대신 서울만 있다는 안내를 남긴다.

### 경합 처리

구를 빠르게 여러 번 누르면 `fetch` 응답 순서가 뒤집혀 옛 결과가 나중에 그려질 수
있다. `renderPanel()` 에 단조 증가 토큰을 두고, `await` 뒤 토큰이 바뀌었으면
그리지 않고 버린다. 선택이 하나뿐일 때는 드러나지 않던 문제다.

### 곁다리로 잡은 것 — `[hidden]` 이 안 먹던 문제

`dashboard.css` 의 `.re-body { display: grid }` 와 `.re-tabs { display: flex }` 가
브라우저 기본 `[hidden] { display: none }` 을 이기고 있었다. 그래서 프리미엄 보기가
`.re-body.hidden = true` 를 걸어도 **지도와 지역 탭이 그대로 보였다** — 사용자가
"프리미엄을 눌러도 지도가 안 변한다"고 한 게 이것이다. 세 대시보드가 모두 화면
전환에 `hidden` 을 쓰므로 `dashboard.css` 에 `.re-app [hidden] { display: none
!important }` 로 한 번 못박는다.

실거래·학군 쪽에서 `hidden` 으로 토글하는 요소(`.re-back-btn`, 각종 heading,
`.re-progression`, `.re-peer-prog`)에는 `display` 규칙이 없어 영향이 없다.

## 규모

| | 값 |
|---|---|
| 서울 노후 단지 전체 | 1,378행 |
| 강남·서초·송파 3구 | 232행 |
| 한 구 최대 | 135행 (노원구) |
| 서울 25개 구 JSON 합계 | 916K (개별 최대 63K) |

개수 상한은 두지 않는다. 25개 구를 다 고르려면 25번 눌러야 하고, 그때도
`sggCache` 덕에 재선택은 네트워크를 타지 않는다.

## 안 하는 것

- 데이터 파이프라인·수집 스크립트
- 단계별 프리미엄 화면 (구별 값이 없어 지도가 없다. 상위 20건만 실려 있어
  구별 집계를 만들면 "승자가 많은 구"의 지도가 된다)
- 선택을 URL 에 남기기 (요청 없음)

## 검증

`_pages/real-estate-*.md` 는 Liquid include 를 써서 그냥 열 수 없다. 저장소 루트에
하네스 페이지를 만들고 헤드리스 크롬 `--dump-dom` 으로 확인한다 (자세한 절차는
메모리 `dashboard-js-harness-verification`).

- 토글: 추가 → 추가 → 같은 구 재클릭으로 제거
- 칩 `×` 와 `모두 지우기`
- 모드 탭 전환 시 선택이 비는지
- 빈 상태 요약 표의 구 클릭으로 선택되는지
- `구` 열이 2곳 이상일 때만 나오는지, 정렬이 숫자로 되는지
- 390px 에서 표만 자체 스크롤 안에서 넘치는지
